# DeepFileX

DeepFileX is a Windows desktop app for finding files by name and searching the text inside documents. The filename list is held in memory, and saved content indexes stay on your computer.

## Download

[Download DeepFileX for Windows x64](https://github.com/HAKARCo/DeepFileX/releases/latest/download/DeepFileX-Setup-x64.exe) or browse the [release history](https://github.com/HAKARCo/DeepFileX/releases).

1. Run `DeepFileX-Setup-x64.exe`.
2. Open **DeepFileX** from the Start menu and approve the Windows administrator prompt for NTFS scanning.
3. Use **Filename** to search the scanned drive, or use **Content → Choose folder…** to build a text index. Check the saved indexes you want to search.

## Requirements

- Windows 10 or 11 on x64 and a local NTFS drive.
- Content search supports TXT, CSV, Markdown, common code and configuration formats, DOCX, XLSX, PPTX, and PDFs with extractable text. Content results reflect the saved index. Rescan to include changes.

## Updates and feedback

Use **Help → Check for updates** to check GitHub Releases or **Help → Export feedback log…** to save a local log you can review before sharing. Report issues on the [GitHub issue tracker](https://github.com/HAKARCo/DeepFileX/issues).
